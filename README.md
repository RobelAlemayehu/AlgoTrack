# AlgoTrack

AlgoTrack is a full-stack web application that syncs and centralizes your solved problems from LeetCode and Codeforces into a single, unified dashboard. Track your progress, add detailed notes with code implementations and complexity analysis, and organize problems by category — all in one place.

## Features

- **Multi-Platform Sync** — Automatically fetch solved problems from LeetCode and Codeforces
- **Unified Dashboard** — View all your problems, stats, and streaks in one place
- **Real-Time Analytics** — Activity heatmaps, weekly charts, difficulty breakdowns, and platform-specific stats
- **Smart Notes System** — Add explanations, code implementations, time/space complexity, and useful resources for each problem
- **Problem Tracker** — Filter by platform, difficulty, tags, and search across all synced problems
- **Compare Profiles** — Head-to-head comparison with any competitive programmer
- **Streak Tracking** — Daily solve streaks with notifications to keep you motivated
- **Responsive Design** — Fully optimized for desktop, tablet, and mobile devices

## Tech Stack

**Frontend:** React, Vite, Tailwind CSS, Recharts, Lucide React

**Backend:** Node.js, Express.js, MongoDB, Mongoose, JWT, Axios, bcryptjs

**APIs:** LeetCode GraphQL API, Codeforces API
